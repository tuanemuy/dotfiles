# 作業ファイルの置き場所（`{scratchpad}`）

使い捨てファイル（下書き・スクリーンショット・サーバーログ / pid・ブラウザプロファイルなど）は、**セッション固有の作業ディレクトリ**に置く。実行環境が提供するもの（Claude Code の scratchpad 等）を使い、無ければ `mktemp -d` で作る。各スキルではこれを `{scratchpad}` と表記する。

**`/tmp/page.png` や `/tmp/foo-server.pid` のような固定パスを使わない。** セッションを並行実行すると踏み合い、スクリーンショットは上書きされ、pid ファイルは他セッションのサーバーを落とす。

`{scratchpad}` はセッション終了で消える前提のものなので、`spec/` などリポジトリ内の成果物からリンクしない。恒久的に残すものはリポジトリ配下にコピーする。
